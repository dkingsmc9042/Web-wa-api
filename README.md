# Web-wa-api

A WhatsApp API web application created via Acode.

## Project Structure

```
vercel-frontend/
├── api/
│   └── [...path].js         # Serverless proxy to backend VPS
├── public/
│   └── index.html           # Combined UI
├── vercel.json              # Vercel routing configuration
└── package.json             # Project dependencies
```

## Overview

This project consists of:

- **API Layer** - Serverless functions that proxy requests to the backend VPS
- **Frontend** - Static HTML UI served from Vercel
- **Configuration** - Vercel routing and Node.js package management
